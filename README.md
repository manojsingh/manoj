# Manoj Singh — personal site

A lightweight personal portfolio built with plain HTML and CSS. It is ready to publish from the root of this repository with GitHub Pages.

## Customize the site

- Edit `index.html` to update the introduction, about section, projects, writing, and social links.
- Add projects or posts by replacing the “More soon” and “Writing, soon” messages with your own content.
- Adjust colors, typography, and layout in `styles.css`.

The site uses no build step or JavaScript. Google Fonts are used when available; system sans-serif fonts are the fallback.

## Publish with GitHub Pages

1. Open the repository’s **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and the `/ (root)` folder, then save.
4. GitHub Pages will publish the site and show its URL in the Pages settings.

If your default branch has a different name, select that branch instead.
